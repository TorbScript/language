Pick the language you already know. Each page is a table you can skim in a few minutes, one short example, and the
habits that are worth unlearning before they cost you a diagnostic.

## What belongs here

A dense, table-first comparison for somebody who already writes the other language well: what maps, what surprises,
what is missing on purpose. What does not belong here: the full argument for a decision, which is in
[explanation/](../../explanation/index.md) - four of these five languages have a longer essay there, and every page
below links to its own.
