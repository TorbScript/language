Programming is telling a computer what to do, one small step at a time. In this course you write real programs from the
first lesson on, right here in the page. Each lesson takes three to five minutes and teaches one idea.

Every lesson has an example you can change and run, a small exercise with a hint and a solution, and one line to
remember. Nothing to install: when you want to run programs on your own computer, the last lesson shows how.

## Who this is for

For anyone who has never programmed, or tried once and gave up. You need no maths beyond adding and multiplying, and
no words from computer science: every new word is shown before it gets a name.

If you already know another programming language, the [guide](../guide/index.md) is faster: it starts from what you
know and shows what is different.

## Pages

- **[Your first program](your-first-program.md)** - A program is a list of instructions that the computer follows from top to bottom, and print is the instruction that shows a line of text.
- **[Names for values](names-for-values.md)** - Give a value a name with const and use the name instead of the value; write var instead when the value has to change later.
- **[Numbers and text](numbers-and-text.md)** - Programs calculate with + - * and /, join text with +, and every value has a type that says what kind of value it is.
- **[Making decisions](making-decisions.md)** - With if and else a program does one thing or another, depending on a question whose answer is true or false.
- **[Repeating things](repeating-things.md)** - A for loop runs the same lines once for every number of a range, and a while loop runs them as long as a question is answered yes.
- **[Lists](lists.md)** - A list holds several values in order, a loop goes through them one by one, and giving a list a second name makes a copy.
- **[Functions](functions.md)** - A function gives a few lines a name, so they can run again with a different value each time, and it can hand a result back.
- **[Your own types](your-own-types.md)** - A type of your own bundles values that belong together, like the name and the age of a pet, and can have functions of its own.
- **[One of several cases](one-of-several-cases.md)** - A type can list the cases a value can be, like sunny or rainy, and match does one thing per case and makes sure no case is forgotten.
- **[When a value might be missing](missing-values.md)** - When a value might not be there - the fourth item of a list with three - the answer says so, and ?? or match decide what happens then.
- **[When something goes wrong](when-things-go-wrong.md)** - A function that can fail says so and answers Ok with its result or Fail with the reason, so every failure is handled where it happens.
- **[A small project](a-small-project.md)** - A reading list that puts every lesson together - a type with cases, a type with fields, a list, a loop and functions - in one program.
- **[Where to go next](where-to-go-next.md)** - Install TorbScript to run programs on your own computer, and pick what to read next - the guide, the reference, or a project of your own.
