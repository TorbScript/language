Pick the language you know best. Each page is a table you can read in five minutes, one short example, and the habits
that are worth dropping before the compiler points them out.

## Who this is for

For people who write one of these languages well and want to see TorbScript through it. For the whole language in one
go, take [the tour](../tour.md).
